# Redis Lite Server

A lightweight Redis-compatible server built from scratch in Python.

Implements the RESP protocol over TCP with multi-threaded concurrency, key-value storage, key expiration, list operations, and disk persistence — achieving **93,000 requests per second**.

## Features

- **RESP Protocol** — Custom serializer and deserializer supporting Simple Strings, Errors, Integers, Bulk Strings, and Arrays
- **TCP Server** — Multi-threaded server handling concurrent client connections
- **Key-Value Storage** — In-memory dictionary-based storage with SET and GET
- **Key Expiration** — Time-to-live support with lazy expiration (EX, PX, EXAT, PXAT)
- **Numeric Operations** — INCR and DECR with validation
- **List Operations** — LPUSH and RPUSH with type checking
- **Persistence** — SAVE command and automatic load on startup via JSON
- **Error Handling** — WRONGTYPE errors, unknown command errors, and graceful client disconnects

## Supported Commands

| Command | Description |
|---------|-------------|
| `PING` | Returns PONG |
| `ECHO <message>` | Echoes the message back |
| `SET <key> <value> [EX seconds]` | Sets a key-value pair with optional expiration |
| `GET <key>` | Retrieves the value for a key |
| `EXISTS <key>` | Checks if a key exists |
| `DEL <key> [key ...]` | Deletes one or more keys |
| `INCR <key>` | Increments an integer value by 1 |
| `DECR <key>` | Decrements an integer value by 1 |
| `LPUSH <key> <value> [value ...]` | Inserts values at the head of a list |
| `RPUSH <key> <value> [value ...]` | Inserts values at the tail of a list |
| `SAVE` | Persists the database to disk |

## Architecture

    Client (redis-cli)
        │
        ▼
    TCP Socket (port 6379)
        │
        ▼
    Thread Pool (one thread per client)
        │
        ▼
    RESP Deserializer → Command Router → RESP Serializer
        │
        ▼
    In-Memory Storage (dict) + Expiry Tracker (dict)
        │
        ▼
    JSON File Persistence (dump.json)

## Project Structure

    redis-server/
    ├── server.py          # Main server: TCP socket, threading, command routing
    ├── serialize.py       # RESP serializer (Python objects → RESP format)
    ├── deserialize.py     # RESP deserializer (RESP format → Python objects)
    ├── dump.json          # Persistence file (auto-generated by SAVE)
    └── README.md

## Getting Started

### Prerequisites

- Python 3.10+
- `redis-cli` (install via `brew install redis` on macOS)

### Running the Server

    python3 server.py

The server starts on `127.0.0.1:6379`.

### Testing with redis-cli

    # Basic commands
    redis-cli PING
    redis-cli SET Name John
    redis-cli GET Name
    redis-cli DEL Name

    # Expiration
    redis-cli SET session abc EX 10
    redis-cli GET session    # returns "abc"
    # wait 10 seconds...
    redis-cli GET session    # returns (nil)

    # Lists
    redis-cli RPUSH mylist a b c
    redis-cli LPUSH mylist z

    # Persistence
    redis-cli SAVE

## Benchmark Results

Tested using `redis-benchmark -t set,get -n 100000 -q` on macOS.

| Metric | Real Redis | Redis Lite | Ratio |
|--------|-----------|------------|-------|
| SET throughput | 169,779 req/s | 92,507 req/s | 1.8x |
| GET throughput | 180,832 req/s | 93,633 req/s | 1.9x |
| SET p50 latency | 0.151 ms | 0.479 ms | 3.2x |
| GET p50 latency | 0.151 ms | 0.423 ms | 2.8x |
